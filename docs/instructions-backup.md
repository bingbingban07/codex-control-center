# 全局指令备份与恢复

`templates/global-instructions/AGENTS.md` 是作者全局指令的可移植版本，保留协作、凭据保护、生图和媒体调用约定。旧电脑用户名、安装路径、具体模型、渠道、推理强度和备用授权已改为默认说明。

这是全局指令模板，不会因为克隆仓库或运行安装器就自动替换你的指令。安装器仍保留本机已有文件。

## 重装后恢复

1. 安装管理台并登录 Codex。
2. 在管理台“技能与指令 → 全局与项目指令”中打开当前全局 `AGENTS.md`。
3. 将模板内容复制到编辑器，预览后保存。如果已有自己的指令，请先备份并合并需要的部分。
4. 通过管理台重新配置需要的模型、生图、媒体和子代理策略，让管理台生成当前电脑适用的路径及受管理指令。

也可手动复制模板：使用自定义 `CODEX_HOME` 时放到该目录的 `AGENTS.md`，否则放到用户目录下 `.codex/AGENTS.md`。不要直接覆盖已有指令。

仓库 Release 的 `AGENTS-portable.zip` 提供相同模板与本说明，可单独下载。该文件是可选恢复包，不含配置、凭据或聊天。

## 项目指令与全局指令

全局指令表达跨项目通用约定。项目 `AGENTS.md` 通常放在项目根目录或子目录，补充该项目的目录结构、构建与测试命令等要求。本次备份时原项目没有独立的 `AGENTS.md`，所以没有冒充备份创建一份项目指令。
