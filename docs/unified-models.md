# 可选统一模型路由

首次安装使用 Codex 原生登录与默认模型，路由来源、目录和子代理分配为空。
安装后在官方 Codex 登录，再运行 `scripts/enable-unified-routing.ps1` 可主动启用统一路由。
它从新电脑的公开模型缓存创建目录；模型名称、Key 和备用策略都需要重新配置。

统一路由保留官方登录，第三方密钥按来源分别使用 Windows 当前用户 DPAPI 保存。
在管理台添加来源和模型后再选择子代理默认项。原版模式恢复官方直连。
工具列表包含完全相同的重复声明时自动合并；冲突定义在发送前明确拒绝。

不会导入旧电脑的登录、聊天、AGENTS、Key、模型名称或个人策略。
