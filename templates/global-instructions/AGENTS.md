## Agent 协作

- 主 Agent 负责需求、方案、结果整合和最终验收；小任务自行完成探索、修改与必要验证。
- 仅在任务边界清楚，且能节省时间、隔离大量中间输出或提供有价值的独立审查时委派子代理；不要机械运行多代理流水线。
- 主代理和子代理的来源、模型、推理强度及失败备用策略由 Codex 管理台管理；本文件不重复指定，代理不得擅自更改。
- 仅并行互不依赖的任务，按需选择代理数量，遵守宿主并发限制，避免重复搜索和覆盖修改。
- 使用完整明文交接任务，写明必要上下文、工作目录、负责范围、限制和验收标准；涉及修改时明确文件所有权，不得撤销其他代理的改动。
- 不要求每次创建任务文件；仅在跨会话交接或审计需要时保存 UTF-8 文件。收到不可读任务时报告并停止，不搜索密钥或其他聊天记录。
- 创建、接入或执行失败时如实报告，保留已完成的工作；不因运行较慢擅自换源或重复执行。

## 默认生图接口（受管理）

- 默认来源读取当前 Codex 用户目录下 `control-center/image-profiles.json` 的 `active_provider`；用户当次明确指定来源、模型或服务时，以当次要求为准。
- 统一调用管理台安装目录内的 `adapters/image-provider/image_dispatch.py`；`--codex-home` 指向当前 Codex 用户目录，提示词文件及输出文件使用绝对路径。不得沿用其他电脑的安装路径。
- 参考图编辑追加可重复的 `--image <绝对路径>`；先用 `--dry-run` 验证。选择 i2m 时遵守已安装的 `i2m-imagegen` 技能；未安装时先报告缺少依赖。
- 未配置来源或凭据时不发起生成；失败、超时或结果不确定时，不自动重试付费请求或改用其他付费来源；如实报告状态。
- 生成后检查并展示实际图片，核对格式与像素尺寸；不静默缩放，不覆盖已有输出。仅为当前任务生成。

## MiniMax 媒体（受管理）

- 当前任务需要语音、配音或视频且本机已配置 MiniMax 时，使用已安装的 `minimax-media` 技能与管理台安装目录内的 `adapters/minimax-media/minimax_media.py`，无需重复询问是否使用已配置来源。
- 仅在用户明确指定 MiniMax 生图时用其生成图片；其他生图遵循默认生图接口。
- 媒体配置读取当前 Codex 用户目录下 `control-center/minimax-media.json`。未配置时先报告；音乐未确认账户权限前不调用，不擅自切换服务或凭据。
- 先 dry-run，再提交一次真实请求；记录视频任务 ID，后续仅查询和下载原任务。超时、取消或提交结果不确定时不自动重新生成。

## 凭据保护

- 不读取、输出或传播明文密钥、认证缓存、请求认证头，不枚举完整环境变量。检测凭据时仅检查已知变量是否存在，输出布尔值。
- DPAPI 凭据仅由受控脚本在实际请求时于内存中解密，不进入模型上下文。

## 默认子代理与失败备用（受管理）

- 首次安装不启用子代理模型分配，不预设来源、模型、推理强度或失败备用。
- 配置启用后，`spawn_agent.model` 仅填写管理台给出的完整模型编号，接入来源是独立信息；禁止拼接来源前缀或对已有斜杠的编号再次添加前缀。
- 创建工具的提示和 `Unknown model` 错误可能只展示前五个候选，不代表完整可用目录。先核对实际提交的编号；尚未返回代理 ID 时不调用 `close_agent`。
- 只有用户在管理台明确配置并启用后，才按本机管理台生成的策略分配模型；本模板不复制其他电脑上的来源和授权。
- 创建、接入或执行失败时如实报告；没有明确失败证据、只是运行较慢或未交付时，不得自动备用。
- 备用策略必须事先获得用户授权；交接完整任务、已完成内容和已有修改，不重复执行已完成的工作。不循环换源。
