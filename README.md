# Codex Control Center / Codex 管理台

Windows x64 / WinUI 3 管理台与可启停的 Codex 增强插件。为 4K、150% 缩放提供较大界面；保留官方 Codex 与增强入口，共享当前电脑上的登录和聊天。

## 重装后直接使用

1. 安装官方 Codex 并登录；安装 Python 3.11+。要使用统一模型路由，再安装 Node.js 22+。
2. 在本仓库 **Releases** 下载 `CodexControlCenter-Windows-x64.zip`，解压到固定目录，保留全部文件。
3. 双击 `安装.cmd`。原生插件注册需要 PATH 中可执行 `codex`；缺少 CLI 时可安装 `npm install -g @openai/codex`。
4. 从桌面“Codex 管理台”打开。在“设置与备份”启用增强功能，按需导入壁纸；正常重开 Codex 加载插件。

安装器自动使用新电脑的用户目录、Python 与应用路径，不依赖任何旧盘符。保留官方 Codex 启动入口，并添加“Codex 增强版”入口。程序包自带 .NET 运行时；从源码编译另需 .NET 10 SDK。

## 首次使用的默认状态

| 项目 | 默认 |
| --- | --- |
| 主模型与登录 | 官方 Codex 自行选择，重新登录 |
| 第三方模型接入/模型列表 | 空白；在管理台自行添加 |
| 子代理分配/失败备用 | 关闭、未指定模型 |
| 路由 | 不接管官方直连；本机空配置、随机新令牌 |
| 生图 | 官方接口模板，无 Key；不发送请求 |
| MiniMax 媒体/音乐 | 未配置、不开启生成 |
| 壁纸 | 关闭；仅附带项目自绘示例背景 |
| 指令、技能、聊天、备份 | 不导入旧电脑数据；另附可选择恢复的通用 AGENTS 模板 |

已有配置文件不会被安装器覆盖。这里公开的是程序与可移植模板，不是当前电脑的配置备份。

全局指令的可移植备份位于 [templates/global-instructions/AGENTS.md](templates/global-instructions/AGENTS.md)，保留通用协作与工具使用约定，不含旧电脑路径或当前模型策略。恢复方法见 [全局指令备份与恢复](docs/instructions-backup.md)；也可在 Releases 单独下载 `AGENTS-portable.zip`。安装器不会自动覆盖已有指令。

## 功能

- 模型来源、模型目录、显示隐藏与中括号标签编辑；默认模型与容量设置。
- 子代理并发分配、默认来源和明确失败后的一次备用策略；用户自行配置。
- 全局/项目指令、技能与角色共用编辑器，跨页面草稿、预览保存与可恢复备份。
- 图片、语音与视频适配器；按配置调用，不自动重试不确定的计费请求。
- 壁纸图库、压暗、构图与局部阅读底色，原生输入框和发送气泡保留。
- 工具重名校验、JSON/SSE/custom 工具兼容、配置热加载和逐来源凭据隔离。
- 原版/增强开关；不修改 WindowsApps 中的官方安装文件。

插件负责本地工具、模式与钩子，窗口美化由独立伴随程序实现。旧电脑额外安装的个人动画、私有主题、个人图片和其他插件不包含在公开包里。

## 可选统一模型列表

官方登录模式默认只显示官方模型。若要同时显示第三方：先启动 Codex 加载官方模型缓存，再运行：

```powershell
./scripts/enable-unified-routing.ps1
```

之后从管理台配置各来源与模型。在原版模式下恢复官方直连。密钥仅在新电脑本地输入，并由当前 Windows 用户加密；没有随源码或发行包上传。

## 从源码构建

```powershell
./scripts/build.ps1 -Publish
./scripts/package.ps1 -SkipBuild
```

完整测试、结构和可选路由说明见 [docs](docs)。本项目是个人开发的非官方增强工具，与 OpenAI 无隶属关系。
